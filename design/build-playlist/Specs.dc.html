How this differs from repair

Reconnect and reconstruct repair playlists that already exist. This screen does the opposite job: it starts from a track list that names no playlist at all, and builds one.

  • Each line is matched against the base collection the same way a disk scan matches a file — by artist and title only, since a text line carries no path, size or time to match on more strictly.
  • The base collection is read, never modified. A brand-new file is written at the path you choose next.
  • A future version may let you resolve an unmatched or ambiguous line here directly. This one shows you the list so you can fix the source file instead.
The output path is not typed directly. It is the playlist name plus the target folder (or the collection's own folder, when target folder is left empty) — the same two fields already on this form.

Buttons

Every button on this screen is filled with the action blue, #56B4E9, its label in the ground, #0F1113, and in the case it is written in. Choose file… and Write playlist share that fill; Write playlist is the primary action by weight, 600 against 500, not by colour. A disabled button takes the off colours, #15171A with a #2A2E32 border and a #8A9299 label, so it never reads as ready to press.

Nothing is written until you press Write. The base collection is never modified.
