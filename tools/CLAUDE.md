# tools/

Repository-level maintenance scripts, kept out of `traktor_nml/` so nothing importable depends on them.

## Files

| File                 | What                                                                                                                                                                                     | When to read                                                                                          |
| -------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------ |
| `preflight.py`       | Four fast session-start checks, each reporting `ok`/`BAD` and all of them running regardless of an earlier failure: which interpreter is in play and which optional packages it carries, that `core.hooksPath` is `hooks` so `hooks/pre-push` is not inert, that the wizard/plan/gate repositories and the handoff document resolve, and that `traktor_nml/gui/app.py` is wholly CRLF. Exit status 1 if anything is wrong; runs no suite | Starting a session, or adding a check for a control that fails silently                               |
| `refresh_handoff.py` | Rewrites the derivable facts in the sibling `CONTINUE-traktor-wizard.md` - the three repository HEADs, the suite's pass/skip counts, the decision log's high-water mark, the `tests/test_gui_*.py` count, and `app.py`'s CRLF/bare-LF counts - each located by an exact anchor pattern, reporting an anchor that no longer matches rather than guessing. `--check` reports drift and writes nothing, exiting 1 when stale. Runs the full suite, and refuses an interpreter carrying `nicegui`/`webview` because the handoff records the system interpreter's pair of counts. Owns `WIZARD`/`PLAN`/`GATE`/`HANDOFF`, which `preflight.py` imports rather than restates | Running `--check` before writing the handoff brief, adding a derived fact, or changing where the four locations resolve |
